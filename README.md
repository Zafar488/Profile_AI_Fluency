# Zafar Ullah — AI Engineer Portfolio

Live URL: [https://zafarullah4050.netlify.app/](https://zafarullah4050.netlify.app/)

Welcome to the official repository for my AI Engineering portfolio. This project serves as a comprehensive showcase of my work in Agentic Workflows, Machine Learning Pipelines, Retrieval-Augmented Generation (RAG), and Computer Vision. 

It was specifically designed and stress-tested as part of the **FlyRank AI Internship (Week 07: Break Your Own Site)**.

## 🚀 Tech Stack

- **Frontend Framework:** React 19 + Vite
- **Animations:** Framer Motion
- **Styling:** Custom CSS + Bootstrap Grid
- **Icons:** Lucide React
- **Hosting & Forms:** Netlify (Serverless Form Handling & Honeypot Bot Protection)

## 🧠 Featured AI / ML Projects

*   **FlyRank ML Capstone (Responsible AI):** An end-to-end privacy-safe machine learning workflow built across Weeks 1–8 of the FlyRank ML Track. Evaluates and prioritizes content-review opportunities.
*   **Fashion AI Studio (Computer Vision):** A ResNet/EfficientNet system for 31 fashion categories with confidence calibration and human-in-the-loop review queues.
*   **AgriMind Pakistan (Agentic AI & RAG):** An 11-agent LangGraph architecture providing bilingual agricultural advisory via FAISS-backed retrieval.
*   **SmogNet (Environmental ML):** Anomaly detection and forecasting pipeline trained on 264K+ rows of air-quality data.

## 🛡️ Security & Hardening (Week 07)

This portfolio has undergone rigorous "Red Team" testing and implements the following production-grade defensive measures:
- State-locked debounce mechanisms to prevent asynchronous form race-conditions.
- Try/Catch error boundary evaluations for network failures.
- Netlify Honeypot integration to silently trap and drop automated spam scrapers.
- Fully semantic HTML with comprehensive OpenGraph and JSON-LD Schema implementations.

## 🛠️ Local Setup Instructions

To run this portfolio locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Zafar488/Profile_AI_Fluency.git
   cd Profile_AI_Fluency
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
